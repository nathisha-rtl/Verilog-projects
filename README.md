# Verilog Projects

This repository contains my Verilog RTL design practice and digital design implementations.

## Topics Covered

### Combinational Circuits
- Half Adder
- Full Adder
- Half Subtractor
- Full Subtractor
- Multiplexer
- Demultiplexer
- Encoder
- Decoder
- Priority Encoder
- Comparator
- Carry Look-Ahead Adder

### Sequential Circuits
- Latches
- Flip-Flops
- Shift Registers
- Registers
- Counters
- Finite State Machines
  - Moore FSM
  - Mealy FSM
  - 101 Sequence Detector

## Tools Used

- Verilog
- Icarus Verilog
- EDA Playground
- GTKWave

Each design includes a Verilog module, testbench, and simulation waveform.
